Why hire me?

Fair question. Short answers.

I've driven cloud-cost-optimization initiatives contributing to roughly $5M in savings — not by cutting corners, but by right-sizing, automating teardown of orphaned resources, and enforcing policy-as-code with tools like Cloud Custodian. Cost control that doesn't compromise reliability is the actual job.
Found teams launching Lambdas by hand? I've bootstrapped fresh AWS accounts with CDK, stood up dedicated git repos, and rebuilt the deployment path so every change to dev or prod flows through a pull request and a stack — never a console click. I've done this repeatedly across Terraform and CDK-based applications.
From ~1,000 VMware ESXi hosts and RAID arrays across retail data centers, to the Kubernetes/EKS backbone of a national 5G network — I'm comfortable being accountable for infrastructure where downtime is not an abstract risk.
Production hands-on experience across AWS, Azure, GCP, and VMware private cloud means I don't just know one vendor's happy path — I know how to translate the same reliability and security principles across platforms.
I actively apply Generative AI and LLM-based automation to accelerate infrastructure troubleshooting and operational data analysis — this website's build process included. I treat AI as leverage on top of solid fundamentals, not a replacement for them.
